An instance placed by a layout element gets an edit node under its path, `CH1`, from the element's `at` and `side`: the `<g>` of the render that takes that `at` is its frame. A layout element with no `at` leaves the instance `computed`. A `<text>` of no part gets an edit node by its uid with its element, unless a layout draws it once per instance.
