One key map for every view: a table of each key and gesture with its command, which the views, a command palette on `/` and a key map overlay on `?` read; `V` cycles the view, `G` the grid, `N` the ratsnest, beside `F`, `+`, `-`, `I`, Escape, `M`, `R`, `L`, `P`, Delete and `Mod+Z`. `pcbjs docs keys` prints the map, generated from the same table.
