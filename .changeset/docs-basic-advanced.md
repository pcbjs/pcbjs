The docs are split into a basic path and advanced topics: `pcbjs docs` lists the basics first, from the new `basics` index that walks a first board end to end, then the rest under `advanced`. The advanced topics `check`, `stackup`, `footprints`, `route-options` and `vscode` hold what a first board does not need. The `pcbjs-basics` skill points at the topics by name, and the extension's README is a short listing page whose reference is `pcbjs docs vscode`.
