A "Get started with pcbjs" walkthrough on the Welcome page, with steps for creating a project, an example board, the preview, `pcbjs check`, inline values, KiCad conversion and the agent skills. Two new commands start a project: `pcbjs: New project from an example` copies one of the example boards, and `pcbjs: New board wizard` asks for the folder, layers, fab, outline and size with every step prefilled, so Enter through it gives a working board. `pcbjs: Run check` runs `pcbjs check` in a project and `pcbjs: Get started` opens the walkthrough.
