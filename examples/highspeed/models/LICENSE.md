# 3D models

These STEP files are KiCad library models, copied unchanged from the packages3D library that ships with KiCad 10.0.6, `SharedSupport/3dmodels` on macOS. Repository: https://gitlab.com/kicad/libraries/kicad-packages3D

| file | KiCad library path |
| --- | --- |
| USB_C_Receptacle_GCT_USB4105-xx-A_16P_TopMnt_Horizontal.step | Connector_USB.3dshapes |
| PinHeader_1x04_P2.54mm_Vertical.step | Connector_PinHeader_2.54mm.3dshapes |
| R_0603_1608Metric.step | Resistor_SMD.3dshapes |

KiCad ships no model of the HRO TYPE-C-31-M-12 the board uses, so J1 shows the GCT USB4105, a 16-pin receptacle on the same land pattern within 0.4 mm.
