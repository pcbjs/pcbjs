## Fetched into a project, never shipped

The standard library names a 3D model for its switches, crystals, connectors, modules and battery holder, by source and alignment only. The cli downloads each file into the project's `.pcbjs/models/fetched/` the first time a board uses the part and writes the source and licence of each in `.pcbjs/models/fetched/LICENSES.md`; no model file is in any package or in this repository.

| Models | Origin | Licence |
| --- | --- | --- |
| `PinSocket`, `JST_PH`, `JST_XH`, four crystals, `CR2032Holder`, four `TactSwitch` sizes | KiCad's `kicad-packages3D` at tag 10.0.7, https://gitlab.com/kicad/libraries/kicad-packages3D, one raw file each, unchanged; an installed KiCad library is used instead when there is one | CC-BY-SA 4.0 with the KiCad library exception, below; attribution: the KiCad library contributors |
| `ESP32C3Mini1` | `ESP32-C3-MINI-1.STEP` of Espressif's KiCad library, https://github.com/espressif/kicad-libraries, at commit dd76561 | CC-BY-SA 4.0 with the same exception, Espressif Systems |
| `TactSwitch('5.1x5.1')`, `SlideSwitch`, `Crystal2012`, `USBC` | EasyEDA's library models of LCSC C318884, C221660, C97603, C165948 and C283540, through `lcsc:` | EasyEDA's terms of use; no licence is stated with the file |

A design may use these models freely under the exception; a project that commits or publishes the fetched files, or a built site with their meshes, keeps the attribution line from `LICENSES.md` beside them and checks EasyEDA's terms for the LCSC ones.

Each `models/LICENSES.md` and each fixture `README.md` or `SOURCES.md` gives the exact source of every file.

## Fonts in a design

A font file a board names in `fonts` is the project's, under its own licence; `pcbjs import` writes the licence of each font it copies to `fonts/LICENSES.md`. docs/fonts.md has the details.
