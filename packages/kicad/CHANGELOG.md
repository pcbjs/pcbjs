# @pcbjs/kicad

## 0.1.0

### Minor Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Release pcbjs 0.1.0 with reusable schematic and layout definitions, synchronized 2D, 3D, schematic and DRC/ERC views, source-driven editing, and resilient editor sessions. Align every component and the bundled VS Code extension on the 0.1 release line.

### Patch Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - `scopeHost(options, root, read)` reads a file's text ahead of the disk, and `typecheck(root, entries, { overlay })` type-checks unsaved editor text without reading or writing `.pcbjs/typecheck.json`. `compileStages` starts a newer schematic epoch before its first stage, so a module evaluated for a compile that ended before `place`, by an error or a cancel, drops its old parts on its next evaluation. The route memos live under `CompileOptions.cache.dir`, in memory when it is null, and a project's footprint folders come from `setKicadConfig`, which the cli calls for every project.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The board importer joins arcs into the route chains of their net, writes copper graphics as chains and pours on no net, part fields as `.source()` on each part in `pcb.sch.ts`, refs as the binding names, a hidden reference as `ref:at={false}`, library models as `kicad:<Lib>.3dshapes/<Name>.step`, project models relative to the module even when missing, and the rules as `defineDefaultBoard({ rules })`. Footprint keepouts are written and built as `keepout(area, { layers })`. `kicadFootprint` and `readFootprint` take `model: { kind: 'none' }` for no model. `pcbjs import board` prints the `defineDefaultBoard` line when it keeps an existing config.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The board importer writes tracks as route chains of `.L()` segments and `.A()` arcs that end on a pad or start from the open end, copper on no net as `pour(null, …)`, `via(null, …)` and `.net(null)`, and keepouts as `keepout(area, { layers })`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - `pcbjs import board` names a pad by its key, `U1.G` or `U1[3]`, writes a stub from a pad to an open point as `route(J1[2], '5 5').Z()` with the pad first, leaves the per-layer colour off the stackup layers and keeps the board's `maskColor` and `silkColor`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A model file is `{ file, offset?, rotate?, scale?, fallback? }`, and a KiCad library model in code is `kicad:<Lib>.3dshapes/<Name>.step`. The compiled footprint keeps the file as written and its absolute `path`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A project's parts, default board, KiCad config, model resolver and source mapper live in one realm that a workspace or the browser compile swaps whole, so two projects in one process never see each other's. The compile takes the default layer as an option, `defaults`, the realm's when left out, and keys its cache on it, so a default one entry sets never serves another entry a stale board. Two copies of `@pcbjs/core` whose realms differ stop with an error naming both, and `pcbjs doctor` reports the realm abi. The editor's "Name this part" action takes the prefix and the refs in use from the compiled boards.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A part's ref is the name of the binding that holds it, in any file and in function bodies of a circuit build; a part made in a loop takes `{ ref }` in its options, and a placed part with no name is a compile error that suggests the next free one, which the language server offers as a code action. Circuit instances take an index, `channel(ports, 2)` or `channel(ports, 'CH2')`, and their parts are numbered from it, `CH2/R01` is `R201`. A bound route is `route:<name>`. A part or a bound route declared and never placed is a compile error. `.connect()` takes pins by name, a factory takes its value as a string then `{ ref, bom, pos, dnp, height, model }`, sourcing and BOM fields are `.source()`, and a placement takes `at`, `side`, `ref:at` and `thermal`. Every footprint on a board is a part, pinless parts included, so nets are `Net` values only and pads are named by their handles. `<Place part>` places a part the file cannot name on the board and in `<Schematic>`, a named `<g>` is a level of hierarchy, and the schematic drawing is the `drawing` export of the schematic module, in grid units. A part never connected, such as a mounting hole, raises no `unconnected-pin`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The platform: everything the compiler reaches outside JavaScript, file reads and listings, sha1, paths, the environment and the disk of the stage cache and route memos, goes through one `Platform` of `@pcbjs/core/platform` on `globalThis`, Node's by default and unchanged in what it does. `memoryPlatform` serves files from memory with a JavaScript SHA-1, POSIX paths and no store. The stage cache, route memos, model paths and `model-missing`, outline fonts, `reference()`, model anchoring, KiCad library reads and STEP mesh keys all use it; `@pcbjs/kicad` and the STEP mesh key import no `node:` module, and opentype.js loads under a bundler too.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Use `ref:at` to position or hide a footprint's reference label. Generated reference labels retain their own source range for precise editor focus, including rotated placements on the back of the board. KiCad imports emit the same attribute.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Each package lists its entries by name. The public entries: `@pcbjs/core` with `jsx-runtime`, `jsx-dev-runtime`, `model`, `ref`, `finding`, `site-data`, `site-facets` and `platform`; `@pcbjs/lib` with `rules`, `stackups` and `impedance`; `@pcbjs/fab` with each preset such as `JLCPCB/2-Layer`; `@pcbjs/compile` with `query` and `browser`; `@pcbjs/export` with `compose` and `browser-worker`; `@pcbjs/step` with `binary`; `@pcbjs/ui` with `style.css`; `@pcbjs/cli` with `vite`, `client`, `test` and `test-register`; `@pcbjs/kicad`, `@pcbjs/lsp` and `@pcbjs/skills` with their root only. The modules the packages import from each other are `./internal/<module>` entries, listed one by one, for packages of the same train only.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Every connector generator returns its footprint factory, as the other generators do: `PinHeader(4)('PZ254V-11-04P')`, `JST_XH(4, { drill })()`, `USBC('power6')('TYPE-C-31-M-17')`. `withPins(factory, names)` renames the pins of a generated footprint or a `kicadFootprint()`. `QFN` takes the exposed pad as the `ep` option. An LED's lens colour is the `color` option of `chip()`, and the named factories `LED0603`, `LED0805` and `LED1206` cover the chip LEDs. `@pcbjs/lib` holds the parts, footprints and helpers; rule sets, stackups and impedance are `@pcbjs/lib/rules`, `@pcbjs/lib/stackups` and `@pcbjs/lib/impedance`. `kicadFootprint` reads library folders from `kicad.footprints` of the config. `pcbjs import board` writes `rev` and a stackup builder for a board without a stackup.

- [`9029beb`](https://github.com/pcbjs/pcbjs/commit/9029beb783788cfbb471cc9d57e1b47864c6eaa6) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - First beta.
