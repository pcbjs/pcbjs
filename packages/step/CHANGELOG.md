### Patch Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The platform: everything the compiler reaches outside JavaScript, file reads and listings, sha1, paths, the environment and the disk of the stage cache and route memos, goes through one `Platform` of `@pcbjs/core/platform` on `globalThis`, Node's by default and unchanged in what it does. `memoryPlatform` serves files from memory with a JavaScript SHA-1, POSIX paths and no store. The stage cache, route memos, model paths and `model-missing`, outline fonts, `reference()`, model anchoring, KiCad library reads and STEP mesh keys all use it; `@pcbjs/kicad` and the STEP mesh key import no `node:` module, and opentype.js loads under a bundler too.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Every source position in the board data is one `SiteSrc`, a file relative to the project root with its line, column and range when it has one; a footprint's `src` and `def` no longer carry an absolute path, and the language server and the editor resolve the file against the root. A referenced board's parts are its footprints' own fields, and its slotted drills keep their length and axis, turned onto this board, so a referenced slot is drawn as a slot rather than a round hole. `StepTransform` is declared once, in `@pcbjs/core/site-data`, and `@pcbjs/step` takes it from there.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Each package lists its entries by name. The public entries: `@pcbjs/core` with `jsx-runtime`, `jsx-dev-runtime`, `model`, `ref`, `finding`, `site-data`, `site-facets` and `platform`; `@pcbjs/lib` with `rules`, `stackups` and `impedance`; `@pcbjs/fab` with each preset such as `JLCPCB/2-Layer`; `@pcbjs/compile` with `query` and `browser`; `@pcbjs/export` with `compose` and `browser-worker`; `@pcbjs/step` with `binary`; `@pcbjs/ui` with `style.css`; `@pcbjs/cli` with `vite`, `client`, `test` and `test-register`; `@pcbjs/kicad`, `@pcbjs/lsp` and `@pcbjs/skills` with their root only. The modules the packages import from each other are `./internal/<module>` entries, listed one by one, for packages of the same train only.

- [`9029beb`](https://github.com/pcbjs/pcbjs/commit/9029beb783788cfbb471cc9d57e1b47864c6eaa6) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - First beta.
