# @pcbjs/lib

## 0.1.0

### Minor Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Release pcbjs 0.1.0 with reusable schematic and layout definitions, synchronized 2D, 3D, schematic and DRC/ERC views, source-driven editing, and resilient editor sessions. Align every component and the bundled VS Code extension on the 0.1 release line.

### Patch Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A generated model carries its own dimensions: `{ kind: 'chip', part, body: [l, w], cap, height, marking? }` for chip passives, `{ kind: 'led', body, height, cap, color?, lens? }` for chip LEDs and `{ kind: 'led', body, height, window, lead, color? }` for PLCC-4 LEDs such as `WS2812B`. `makeFootprint` fills a `chip` or `led` model's `body` and `height` from the definition's, and `chip()` and `PinHeader` are `makeFootprint` definitions like every other stdlib family, so `withPins` renames their pins too. `GENERATED_KINDS` and `isGenerated` in `@pcbjs/core/internal/model-source` list the generated kinds the `ModelSpec` union is built from.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The package ships `LICENSES.md` beside `LICENSE`, with the origin and licence of its footprint data and of the models it fetches, and the KiCad library exception.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - `withPins` on a factory with untyped pins, such as a `kicadFootprint`, types the pin names it gives, so `withPins(kicadFootprint(id), { G: 'G' })('x').G` type-checks.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A model file is `{ file, offset?, rotate?, scale?, fallback? }`, and a KiCad library model in code is `kicad:<Lib>.3dshapes/<Name>.step`. The compiled footprint keeps the file as written and its absolute `path`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - `MountingHole(d, { pad, plated })` takes its copper ring as an option: `pad` is `true` for twice the drill or a diameter, `plated: false` leaves the hole unplated with the ring on both outer layers. The ring is on no net until `.connect({ 1: GND })` ties it.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - A part's ref is the name of the binding that holds it, in any file and in function bodies of a circuit build; a part made in a loop takes `{ ref }` in its options, and a placed part with no name is a compile error that suggests the next free one, which the language server offers as a code action. Circuit instances take an index, `channel(ports, 2)` or `channel(ports, 'CH2')`, and their parts are numbered from it, `CH2/R01` is `R201`. A bound route is `route:<name>`. A part or a bound route declared and never placed is a compile error. `.connect()` takes pins by name, a factory takes its value as a string then `{ ref, bom, pos, dnp, height, model }`, sourcing and BOM fields are `.source()`, and a placement takes `at`, `side`, `ref:at` and `thermal`. Every footprint on a board is a part, pinless parts included, so nets are `Net` values only and pads are named by their handles. `<Place part>` places a part the file cannot name on the board and in `<Schematic>`, a named `<g>` is a level of hierarchy, and the schematic drawing is the `drawing` export of the schematic module, in grid units. A part never connected, such as a mounting hole, raises no `unconnected-pin`.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Each package lists its entries by name. The public entries: `@pcbjs/core` with `jsx-runtime`, `jsx-dev-runtime`, `model`, `ref`, `finding`, `site-data`, `site-facets` and `platform`; `@pcbjs/lib` with `rules`, `stackups` and `impedance`; `@pcbjs/fab` with each preset such as `JLCPCB/2-Layer`; `@pcbjs/compile` with `query` and `browser`; `@pcbjs/export` with `compose` and `browser-worker`; `@pcbjs/step` with `binary`; `@pcbjs/ui` with `style.css`; `@pcbjs/cli` with `vite`, `client`, `test` and `test-register`; `@pcbjs/kicad`, `@pcbjs/lsp` and `@pcbjs/skills` with their root only. The modules the packages import from each other are `./internal/<module>` entries, listed one by one, for packages of the same train only.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Every connector generator returns its footprint factory, as the other generators do: `PinHeader(4)('PZ254V-11-04P')`, `JST_XH(4, { drill })()`, `USBC('power6')('TYPE-C-31-M-17')`. `withPins(factory, names)` renames the pins of a generated footprint or a `kicadFootprint()`. `QFN` takes the exposed pad as the `ep` option. An LED's lens colour is the `color` option of `chip()`, and the named factories `LED0603`, `LED0805` and `LED1206` cover the chip LEDs. `@pcbjs/lib` holds the parts, footprints and helpers; rule sets, stackups and impedance are `@pcbjs/lib/rules`, `@pcbjs/lib/stackups` and `@pcbjs/lib/impedance`. `kicadFootprint` reads library folders from `kicad.footprints` of the config. `pcbjs import board` writes `rev` and a stackup builder for a board without a stackup.

- [`9029beb`](https://github.com/pcbjs/pcbjs/commit/9029beb783788cfbb471cc9d57e1b47864c6eaa6) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - First beta. The standard library: footprints and parts with 3D models fetched from KiCad, Espressif or LCSC on first use, values, the `<Brand>` mark, and the rule sets, stackups and trace impedance of the fabs.
