# @pcbjs/fab

## 0.1.0

### Minor Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Release pcbjs 0.1.0 with reusable schematic and layout definitions, synchronized 2D, 3D, schematic and DRC/ERC views, source-driven editing, and resilient editor sessions. Align every component and the bundled VS Code extension on the 0.1 release line.

### Patch Changes

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - The stackup alone sets a board's copper layers and thickness, `stackup={fourLayer({ thickness: 1.2 })}`; its `maskColor` and `silkColor` colour both sides. `defineDefaultBoard` carries the default rules. Outline fonts are declared on `<PCB fonts>` as `{ file, weight? }`, and `<text font>` is a name; `hershey` is the default stroke font. A variant target gives `rules` and `fabNotes` on the target and the rest of the board under `board`. A preset module default-exports its component, whose data is `PCB.preset`. `BASE` and `mergeRules` come from `@pcbjs/lib/rules`, `isBoundPCB` from `@pcbjs/fab`. Palette names match whatever their case, spaces, `_` or `-`, in a preset and in `maskWebByColor` alike. Sourcing keys and tags match as written, `MPN` in capitals. `repo` is `{ url, ref?, dir?, kind? }`. An entry default-exports the `<PCB>` element.

- [`c27688c`](https://github.com/pcbjs/pcbjs/commit/c27688cce51818a4448a580bc708b5f389a9a74e) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - Each package lists its entries by name. The public entries: `@pcbjs/core` with `jsx-runtime`, `jsx-dev-runtime`, `model`, `ref`, `finding`, `site-data`, `site-facets` and `platform`; `@pcbjs/lib` with `rules`, `stackups` and `impedance`; `@pcbjs/fab` with each preset such as `JLCPCB/2-Layer`; `@pcbjs/compile` with `query` and `browser`; `@pcbjs/export` with `compose` and `browser-worker`; `@pcbjs/step` with `binary`; `@pcbjs/ui` with `style.css`; `@pcbjs/cli` with `vite`, `client`, `test` and `test-register`; `@pcbjs/kicad`, `@pcbjs/lsp` and `@pcbjs/skills` with their root only. The modules the packages import from each other are `./internal/<module>` entries, listed one by one, for packages of the same train only.

- [`9029beb`](https://github.com/pcbjs/pcbjs/commit/9029beb783788cfbb471cc9d57e1b47864c6eaa6) Thanks [@zhangyx1998](https://github.com/zhangyx1998)! - First beta. `bindPCB` and the fab presets, such as `@pcbjs/fab/JLCPCB/2-Layer`, which set the rules, the stackup and the mask web by colour for one fab and layer count.
